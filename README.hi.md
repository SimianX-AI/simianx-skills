## SimianX क्या-क्या करता है

ज़्यादातर काम इन्हीं दो से होता है।

- **लाइव मल्टी-एजेंट विश्लेषण।** कोई शेयर या क्रिप्टो जोड़ी और टाइमफ़्रेम चुनें, चार एजेंट एक साथ उसे पढ़ने लगते हैं। इंडिकेटर एजेंट चार्ट पढ़ता है। इंटेलिजेंस एजेंट ख़बरें पढ़ता है। फ़ंडामेंटल एजेंट फ़ाइलिंग और इनसाइडर सौदे पढ़ता है, और कॉइन हो तो ऑन-चेन और डेरिवेटिव्स डेटा। निर्णय एजेंट तीनों की राय तौलकर एंट्री, स्टॉप और टारगेट के साथ एक ट्रेड सुझाता है। → [लाइव विश्लेषण](https://www.simianx.ai/l)
- **स्कोर की गई ख़बरों की स्ट्रीम।** हर लेख पहले से टैग होकर आता है: वह किन सिंबल पर असर डालता है, उसका वैल्यू स्कोर, और रुख़ तेज़ी का है, मंदी का या तटस्थ। मार्केट पल्स इसी फ़ीड पर चलता है, जहाँ ये ख़बरें कीमत की अचानक चालों, नए हाई और लो और गैप के साथ दिखती हैं। आपका एजेंट इसे पेज-दर-पेज पढ़ सकता है या अपने सिंबल पर स्ट्रीम खुली रख सकता है। → [मार्केट पल्स](https://www.simianx.ai/pulse)

ज़रूरत हो तो ये भी हैं:

- **गहन रिसर्च।** आठ एजेंट किसी शेयर या कॉइन पर बहस करते हैं और फ़ैसला, ट्रेड प्लान और एक PDF लेकर लौटते हैं। आपका एजेंट आगे सवाल भी पूछ सकता है। → [गहन विश्लेषण](https://www.simianx.ai/c)
- **सेक्टर वॉच।** मूल स्रोतों से लिए गए कैटलिस्ट कैलेंडर और इवेंट, शुरुआत बायोफ़ार्मा से। → [सेक्टर वॉच](https://www.simianx.ai/sectors)
- **ऑटोपायलट।** वही चार लाइव एजेंट एक सिंबल पर तय शेड्यूल से चलते हैं, साथ में एक पेपर पोज़िशन और एक इवेंट लॉग, जिसे आपका एजेंट फ़ॉलो कर सकता है। → [स्वचालित पायलट](https://www.simianx.ai/autopilots)
- **मॉडल आपकी पसंद का।** हर एजेंट के पीछे कौन-सा मॉडल चले, यह आप चुनें, और चुनने से पहले देख लें कि हर मॉडल ने अब तक कैसा ट्रेड किया है। → [मॉडल लीडरबोर्ड](https://www.simianx.ai/crypto-leaderboard)

बाज़ार: 13,000+ अमेरिकी शेयर और ETF, `1m` से `1mo` तक की कैंडल पर, और 4,000+ क्रिप्टो जोड़ियाँ (स्पॉट और परपेचुअल), `1m` से `1D` तक। → [स्टॉक विश्लेषण](https://www.simianx.ai/c) · [क्रिप्टोकरेंसी विश्लेषण](https://www.simianx.ai/l)

## एक वाक्य में इंस्टॉल

यह वाक्य अपने एजेंट में पेस्ट करें:

```text
Install the SimianX skill from https://www.simianx.ai/INSTALL.md and set it up for this project.
```

एजेंट skill को वहाँ रख देता है जहाँ वह skills ढूँढता है, फिर आपको साइन इन कराता है: ब्राउज़र में एक लिंक को मंज़ूरी दें, या ईमेल पर आया 6 अंकों का कोड डालें। नए ईमेल पते पर उसी वक़्त खाता बन जाता है। आख़िर में एजेंट के पास `SIMIANX_API_KEY` में उसकी अपनी API कुंजी होती है; आपका वेबसाइट लॉगिन उसे कभी नहीं मिलता।

या टर्मिनल से:

```bash
npx skills add SimianX-AI/simianx-skills
gh skill install SimianX-AI/simianx-skills simianx
```

हर एजेंट (Claude Code, Codex, Cursor, Copilot, Gemini CLI, Windsurf, Amp, Cline और बाकी) का कमांड और डायरेक्टरी [INSTALL.md](INSTALL.md) में है।

### या MCP से जोड़ें

MCP समझने वाले AI एजेंट स्किल इंस्टॉल किए बिना SimianX को टूल्स की तरह इस्तेमाल कर सकते हैं। अपनी कुंजी के साथ रिमोट सर्वर एक बार जोड़ें:

```bash
claude mcp add --transport http simianx https://service.simianx.ai/v1/mcp --header "Authorization: Bearer $SIMIANX_API_KEY"
```

Claude Desktop, Cursor, Codex, VS Code, Windsurf और Gemini CLI के लिए यही तरीका [INSTALL.md](INSTALL.md#connect-over-mcp) में है। रजिस्ट्री नाम: `io.github.SimianX-AI/simianx`।

## शुरुआती कॉल

| काम | कॉल | संदर्भ |
|---|---|---|
| लाइव विश्लेषण, एक बार | `POST /v1/analysis/live` → `GET /v1/analysis/live/{id}?wait=30` | [live](skills/simianx/references/live.md) |
| आपके सिंबल की ख़बरें | `GET /v1/news?symbols=NVDA&min_value=medium` | [news](skills/simianx/references/news.md) |
| ख़बर आते ही | `GET /v1/news/stream` (server-sent events, कनेक्शन टूटे तो वहीं से जारी) | [news](skills/simianx/references/news.md) |
| मार्केट पल्स | `GET /v1/pulse/events` | [data](skills/simianx/references/data.md) |
| गहन रिसर्च | `POST /v1/analysis/deep` → `/events` · `/ask` · `/pdf` | [deep](skills/simianx/references/deep.md) |
| सेक्टर वॉच | `GET /v1/sectors/{sector}/calendar` · `/events` | [sectors](skills/simianx/references/sectors.md) |
| ऑटोपायलट | `POST /v1/autopilots` → `GET /v1/autopilots/{id}/events?after=<cursor>&wait=30` | [autopilots](skills/simianx/references/autopilots.md) |

बेस URL `https://service.simianx.ai/v1` है, हेडर `Authorization: Bearer $SIMIANX_API_KEY`। यही कॉल shell स्क्रिप्ट के रूप में [examples/curl](examples/curl) में हैं।

## प्लान

Free, Starter, Plus और Pro; विवरण के लिए [कीमतें](https://www.simianx.ai/pricing) देखें। एजेंट की कॉल आपके प्लान के पॉइंट्स से चलती हैं, उन्हीं दरों पर जो वेबसाइट पर हैं। ख़बरों की स्ट्रीम Plus और Pro पर लाइव है; Plus से नीचे के प्लान में ख़बरें 30 मिनट देर से आती हैं। जवाब 16 भाषाओं में मिलते हैं। SimianX कभी किसी असली खाते में ट्रेड नहीं करता: ऑटोपायलट की पोज़िशन पेपर पोज़िशन होती हैं।

## सुरक्षा

- कुंजी `SIMIANX_API_KEY` में ही रहती है। skill उसे कभी रिपॉज़िटरी, लॉग या प्रॉम्प्ट में नहीं लिखती।
- एजेंट को वेबसाइट सेशन कभी नहीं मिलता। एजेंट से साइन इन करने पर सिर्फ़ उसी एजेंट के लिए एक API कुंजी बनती है, और ऐसा होते ही हम आपको ईमेल करते हैं।
- हर कुंजी के अपने scope और दैनिक व मासिक बजट होते हैं, और चाहें तो IP allowlist भी। हर एजेंट को सबसे सीमित कुंजी दें जिससे उसका काम चल जाए।
- **मेरा खाता → API कुंजियाँ** में कुंजी रद्द करें, एक सेकंड के भीतर वह काम करना बंद कर देगी।

## संस्करण

skill अपना संस्करण `X-SimianX-Skill` हेडर में भेजती है। कोई संस्करण बंद होने पर API `426` लौटाता है, साथ में वह URL जिसे दोबारा पढ़ना है; `GET /v1/skill` मौजूदा और न्यूनतम संस्करण बताता है। अपडेट के लिए अपने एजेंट का अपना कमांड चलाएँ या ऊपर वाला वाक्य फिर से पेस्ट करें। क्या बदला, यह [चेंजलॉग](CHANGELOG.md) में है।
